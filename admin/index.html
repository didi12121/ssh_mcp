      新增连接

      首次连接时，请在 MCP 服务端的 known_hosts 登记已核验的目标主机公钥，再测试连接。

      如何核对并登记主机指纹
      1. 通过目标服务器的控制台或已有可信终端运行 ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub，核对 ED25519 指纹。
      2. 核对后，将目标服务器的主机公钥加入 MCP 服务端 PTMCP_KNOWN_HOSTS 指定的文件，使用表单中填写的地址。非默认端口使用 [主机]:端口。

      「安装公钥」更新目标账号的 authorized_keys，用于允许该账号登录。若已有主机指纹发生变化，请先确认变更原因，再更新记录。

      在目标服务器安装 tmux

      持久终端需要目标服务器提供 tmux 和 python3。登录目标服务器后，用 cat /etc/os-release 确认发行版，再选择安装命令。以 root 登录时去掉 sudo。

      Ubuntu / Debian

      sudo apt update
sudo apt install tmux python3

      Fedora

      sudo dnf install tmux python3

      安装后执行 tmux -V，再回到管理页点「测试连接」。如果仍未检测到，请检查 SSH 登录账号的 PATH。
